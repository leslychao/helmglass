# Helm Glass — рабочая матрица приёмки

Каноническая карта всех 187 условий разделов 1–18 [функциональной спецификации](Helm-Glass-functional-spec.md). Источник визуального оформления — [итоговый каскад V12](Helm-Glass-v12.html). Условия, владельцы, проверки и код отделены от фактической приёмки.

Статусы: `NOT_RUN` — сценарий не выполнен; `PASS` — полное условие подтверждено наблюдением; `PARTIAL` — подтверждена только указанная часть; `FAIL` — найдено нарушение, устранение ещё не подтверждено; `BLOCKED` — указана внешняя причина. Код и сборка не означают прохождения пользовательского маршрута. Свидетельство указывает стенд, действие, результат и время без секретов.

Итог на 2026-10-08: **172 PASS, 10 PARTIAL, 5 BLOCKED, 0 FAIL, 0 NOT_RUN** — 187 уникальных условий. Последнее развёртывание dev: frontend собран в 09:28:57 UTC, API — в 09:29:05 UTC; штатный deploy завершился успешно. Все обнаруженные дефекты имеют подтверждённое исправление, но составные ручные проверки и внешний аудиосценарий ещё не завершены; полная готовность не заявляется.

Приёмка выполняется на `https://helmg.ru` через оба Nginx, штатные OIDC/PKCE и текущий аккаунт ChatGPT. Свидетельства в строках различают публичный API, worker/runtime, настоящий Chrome/noVNC/ChatGPT и controlled host. Отдельный локальный стенд не поднимался. Штатные повторные развёртывания сохраняют данные и ждут подтверждённого освобождения браузеров; работающие браузеры принудительно не закрывались.

Актуальность определяется последним свидетельством каждой строки. Исправления проверяются адресно после dev deploy, включая первоначальный отказ там, где он воспроизводился. `UI_PRESENT` и `UI_FIXED` в колонке ревью показывают наличие пути в исходниках и не заменяют фактическую приёмку. Общие сборки и отдельные HTTP-проверки не доказывают прохождения составного пользовательского маршрута.

Настоящий ChatGPT подключён к `test`; создание/чтение/исполнение задач, виджет, вопрос/ответ, автоматическое продолжение и переход в кабинет проверены. Ключевые связанные проверки находятся у владельцев: [API contracts](../backend/api/tests/), [browser session](../backend/browser-session/test/), [browser lifecycle](../backend/browser-node/test/), [egress](../backend/egress/test/) и [widget](../backend/api/widget/test/continuation.mjs).
